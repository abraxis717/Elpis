This is a separate C11 candidate, not part of the root build, installed host catalog, active architecture, ABI inventory or published Elpis. `gd_*` names are provisional. Geometry is immutable after creation. Callers supply correctly sized buffers and serialize object lifetime; arbitrary/dangling C pointers are outside the ABI contract. Multiple indexes are independent. Retaining spherical coordinates and face arrays is a deliberate initial parity choice; later profile whether to discard these arrays after construction. The C typed API encodes prefixes by depth and radix-7 code and accepts int32 lattice coordinates, unlike Python's arbitrary bounded integers. Depth-7 rooted descendants fit int32; coordinates outside the rooted domain refuse. No sparse state, handles, scheduler, FMS, CGC or semantic authority is implemented.

Offline `tests/parity.py` checks pinned hashes, exhaustive native code round trips, all directed arcs, all prefix counts and pages, and a direct oracle differential for vertices, coordinates, faces, neighbors, arcs and selected prefixes. With no reference path it is only a hash smoke test. `test_alloc.c` injects each direct constructor allocation failure and checks zero direct allocation calls in query loops; libc internal allocation and OS writes are not measured by this wrapper. No scientific utility claim. Full CR1 remains HOLD pending sparse state, scheduler, adversarial and containment tests. Runtime internal digest verification and final ABI admission remain future work.
