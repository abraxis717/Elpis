# Elpis2.2.1

## Version: v2.2.1

Elpis2.2.1 is a release-information coherence corrective successor to the
immutable `Elpis2.2.0` tag.

Elpis2.2.0 passed source, main-push, tag and tag-CI qualification, but its sealed
README still presented the Elpis2.1.27 release summary. Because README is also
the Python distribution long description, the tag is retained as immutable
evidence but is not eligible for GitHub Release or PyPI publication.

This successor updates the public description to match actual qualified
repository authority, including the Grid81 writer chain, E0R3 participation
referents, ECS topology projection/analysis, DurableApplicationLedger v2,
bounded ingress components, and current release-integrity/portability gates.

The 16-component public registry membership remains unchanged and every entry
retains `runtime_admission=false`; only documentation/source hyperlinks are
added. Qualified writer-chain successor components remain separately registered
with `public_registry_admission=false` and `runtime_admission=false`.

A permanent release-information coherence test now binds README claims against
the public registry, writer successor registry, 2.2 adoption policy, and failed
release authority.
