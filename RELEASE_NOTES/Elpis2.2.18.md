# Elpis2.2.18

## Version: v2.2.18

Elpis2.2.18 corrects post-publication closeout mechanics exposed by published Elpis2.2.17. Git-bearing checkouts continue to require exact tag-derived PUBLISHED authority. Git-less mutation/export copies cannot prove Git refs, so they enforce metadata and prior-record prefix immutability while deferring only that unavailable projection proof.
